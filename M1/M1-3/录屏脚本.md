# 录屏：照着点就行（10 分钟搞定）

> 你要做的只有一件事：**录一段 4 分钟左右的视频，证明 `use_sim_time` 开/关会改变节点行为**。
> 不需要你写代码、不需要你敲长命令，脚本已经把 6 步全排好了。

---

## 第 0 步：确认东西都在（1 分钟）

桌面上的 `usky` 文件夹里应该有：`M1/M1-3/scripts/record_demo.sh`。
WSL 里能看到它，命令是 `ls` 一下就知道，不用管。

---

## 第 1 步：打开 Ubuntu 终端

**操作A（推荐）**：点 Windows 开始菜单 → 直接输入 `Ubuntu` → 点那个橙色圆圈的图标 → 弹出一个黑色窗口。
**操作B**：打开"终端"(Windows Terminal) → 窗口顶部标签栏右侧有个下拉箭头 `∨` → 选 `Ubuntu`。

打开后看到类似这一行就对了：

```
usky@LAPTOP-AB9BCF52:~$
```

> 注意：**不能用 PowerShell / cmd**（那是 Windows 的，里面没有 `ros2`）。必须是这个 Ubuntu 窗口。

---

## 第 2 步：进到 M1-3 目录（复制粘贴 1 行，回车）

```bash
cd /mnt/c/Users/admin/Desktop/usky/M1/M1-3
```

粘贴方法：在这个窗口里点右键就是粘贴（或 `Ctrl+Shift+V`）。回车后提示符会变成以 `M1-3` 结尾：

```
usky@LAPTOP-AB9BCF52:/mnt/c/Users/admin/Desktop/usky/M1/M1-3$
```

---

## 第 3 步：开始录制

按 **`Win + Alt + R`**（三个键一起按）。

- 屏幕右上方会冒出一个小的黑色控制条 + 一个计时器开始走（`00:00:03` 这样）。
- 如果**毫无反应**：按 `Win + G`，打开 Game Bar 面板，点面板里的 ● 录制按钮，效果一样。
- 第一次用可能弹"这是游戏吗？"的询问框，选"是"。

> Game Bar 只能录**当前最前面的那个窗口**。开始录制前，先用鼠标点一下那个 Ubuntu 黑窗口，让它变成最前面。

---

## 第 4 步：跑脚本，中间按 6 次回车

在黑窗口里粘贴这一行并回车：

```bash
bash scripts/record_demo.sh
```

然后脚本会自己往下走，**每走完一步停下来等你按回车**。你只要：

1. 看一眼屏幕上新出现的东西，用**自己的话**说一句它在证明什么；
2. 按一下 `回车`；
3. 重复。总共按 6 次回车。

> **别背台词。** 下面是"如果一时想不出说什么"的口语版参考，照着念也不会像念稿；
> 你按自己的说法讲，只要意思对上就行，讲错一句重录也无所谓。

| 走到第几步 | 屏幕上会出现 | 口语版参考（可不照读） |
| :-- | :-- | :-- |
| `[1/6]` | `extrinsics.yaml` 里 laser_link / camera_link / fx 的数值 | "安装位置和相机内参都写在这个文件里，我代码里没写死，改这个文件就能换外参。" |
| `[2/6]` | bag 的 Duration、话题列表 | "这几个话题的数据是我用 make_bag 现场生成的。得放在 WSL 自己的盘上，放 Windows 盘上回放基本读不出数据。" |
| `[3/6]` | 4 行 `[TF] map -> odom` / `odom -> base_link` / `base_link -> laser_link` / `base_link -> camera_link` | "四个变换：map 到 odom，odom 到 base_link，base_link 再分给激光和相机。" |
| `[4/6]` | `[CLOCK] use_sim_time=True｜节点时钟=1.4 s｜首帧 stamp=1.2 s｜差=0.2 s` | "这是开着仿真时间的，节点自己的时间跟消息上的时间戳基本对得上，就差零点几秒。" |
| `[5/6]` | `[CLOCK] use_sim_time=False｜节点时钟=1.79e9 s｜首帧 stamp=0.1 s｜差=1.79e9 s` | "同一个数据、同一个回放，我把仿真时间关了，节点改用电脑的墙钟，跟消息差了五十多年。" |
| `[6/6]` | 三条结论 + 自动弹出一张投影图 | "所以这俩得配套：要么开仿真时间、回放带 clock，要么都不开。只开一边、或者忘了 clock，时间就全乱了。" |


> 第 4 步回放数据时屏幕会刷一屏日志、大约 15 秒，**别慌，等它自己停**，那是正常的。

---

## 第 5 步：停止录制

再按一次 **`Win + Alt + R`**。计时器消失，视频就已经落盘了。

---

## 第 6 步：把视频找出来、改个名

游戏栏默认存在：

```
C:\Users\admin\Videos\Captures\
```

里面最新那个 `.mp4`（名字类似 `录制_2026-11-12_22_45_03.mp4`）就是。把它**剪贴/移动**到桌面，重命名成：

```
m1_three_use_sim_time.mp4
```

（放在桌面就好，**不要放进 usky 仓库**，视频不进 git。）

---

## 第 7 步：自检（30 秒）

双击播放，检查 3 件事：

- [ ] 能看清 `[TF]` 那 4 行（证明坐标树）
- [ ] 能看清 `[CLOCK]` 那两行（true 一行、false 一行）—— **这是本题唯一的必拍证据**
- [ ] 结尾弹出过一张投影图（黑底 + 三个色块 + 一排红蓝小点）

三样都有就可以交，录不成再录一次，脚本随时可以重跑（`Ctrl+C` 中止也行，它会自己清理节点）。

---

## 常见卡住与处理

| 现象 | 原因 | 怎么办 |
| :-- | :-- | :-- |
| 提示 `bash: scripts/record_demo.sh: No such file or directory` | 没在第 2 步那个目录里 | 重新粘贴第 2 步那行 `cd ...`，再跑第 4 步 |
| 提示 `ros2: command not found` | 用了 PowerShell 而不是 Ubuntu 窗口 | 关掉重开，认准橙色圆圈 Ubuntu 图标 |
| `[3/6]` 之后一行 `[TF]` 都没有 | 之前有残留进程占着 | 脚本开头会自动清理；再跑一次即可 |
| 第 4 步卡住不动、十几秒没反应 | bag 被放到了 Windows 盘 | 本脚本已把 bag 生成在 `~/m13_bag`，若你手动放的请删掉重生成 |
| `Win+Alt+R` 完全没反应 | 系统没开游戏栏 | `Win+G` → 面板里点录制；或设置里搜"游戏栏"打开录制 |

## 备选：考官要求你自己敲命令（不用脚本）

三个 Ubuntu 窗口，依次：

```bash
# 窗口A
ros2 run m1_three static_tf_publisher

# 窗口B
ros2 run m1_three projection_node --ros-args -p use_sim_time:=true \
    -p extrinsics_file:=extrinsics.yaml -p output_dir:=demo_out -p max_images:=2

# 窗口C
ros2 bag play ~/m13_bag --clock --rate 2.0
```

再看一眼 TF 树：

```bash
ros2 run tf2_tools view_frames        # 终端里直接打印整棵树
ros2 run tf2_ros tf2_echo base_link camera_link   # Translation: [0.100, 0.000, 0.300]
```
