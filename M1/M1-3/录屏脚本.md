# 录屏脚本（Windows 自带录屏）

> 目标：录一段能证明"`use_sim_time` true ↔ false 行为会变"的视频，顺带把 TF 树和投影也录进去。
> 录制工具：**Win + Alt + R** 开始/结束（或 Win + G 打开 Game Bar 再点录制）。
> 建议先录一次 30 秒的空镜练手，确认能录到窗口。

---

## 一、录前准备（2 分钟）

```bash
cd ~/usky/M1/M1-3
source /opt/ros/humble/setup.bash
colcon build --symlink-install && source install/setup.bash
```

把终端字号调大（`Ctrl + 滚轮`），保证视频里字看得清；窗口拉到屏幕 2/3 宽。

---

## 二、录制主线：一条命令（推荐）

```bash
bash scripts/record_demo.sh
```

脚本会**一步一步停下来等你按回车**，每一步都打印"这一步该看到什么"。
按 `Win+Alt+R` 开始录制，然后每按一次回车念一句，6 步大概 4–5 分钟。

| 步 | 画面里应该出现 | 你要说的那句（一句话即可） |
| :-- | :-- | :-- |
| 1 | `extrinsics.yaml` 的 `laser_link` / `camera_link` / `fx` | "TF 的数值全部从这份真值文件读，代码里没有写死的安装位置" |
| 2 | `ros2 bag info` 的 Duration，和"放 /mnt/c 会零条"的对比说明 | "bag 必须放 WSL 原生盘，放 Windows 盘会卡到一条都出不来" |
| 3 | 4 行 `[TF] map→odom→base_link→laser_link/camera_link` | "整棵树四段，父子关系就是题面那张图" |
| 4 | `[CLOCK] use_sim_time=True｜节点时钟=0.6 s｜首帧 stamp=0.1 s｜差=0.5 s` | "开了仿真时间，节点时钟跟着 /clock 走，差值只剩投递滞后的零点几秒" |
| 5 | `[CLOCK] use_sim_time=False｜节点时钟=1.79e9 s｜差≈1.79e9 s` | "关掉仿真时间，节点用墙钟，和消息戳差了 55 年" |
| 6 | 结论 3 条 + 收尾 | "所以两者必须成对：要么都开+--clock，要么都不用" |

## 三、如果考官要求"你自己敲命令"（备选：三终端版）

不想用脚本就开三个终端，顺序照抄，每条命令后面是要看到的画面：

```bash
# 终端 A —— 静态 TF 树
ros2 run m1_three static_tf_publisher
# 看到 4 行 [TF] ... 即成功

# 终端 B —— 投影节点（录屏重点看这里的 [CLOCK] 行）
ros2 run m1_three projection_node --ros-args \
    -p use_sim_time:=true -p extrinsics_file:=extrinsics.yaml \
    -p output_dir:=demo_out -p max_images:=2 -p slop:=0.06

# 终端 C —— 回放
ros2 bag play ~/m13_bag --clock
```

切换演示：

```bash
# 1) Ctrl+C 掉终端 B，改成 false 再起
ros2 run m1_three projection_node --ros-args -p use_sim_time:=false ...
# 2) 再回放一次 bag（终端 C），对比 [CLOCK] 那两行
```

TF 树单独录一眼：

```bash
ros2 run tf2_tools view_frames      # 生成 frames_*.pdf，终端里会打印整棵树
ros2 run tf2_ros tf2_echo base_link camera_link   # 看到 Translation [0.1, 0, 0.3]
```

## 四、录完检查清单

- [ ] 视频里能看清 `[CLOCK]` 那两行（true 和 false 各一次），这是本题唯一的"必须镜头"证据
- [ ] 能看到 4 行 `[TF]` 或 `view_frames` 打印的树
- [ ] 能看到 `demo_out/` 里有 png 生成
- [ ] 视频长度 3–6 分钟，没有长时间卡顿（卡住通常是 bag 放在了 `/mnt/c`）
